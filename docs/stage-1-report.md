# Этап 1 — отчёт

Дата: 2026-10-13. Объём: архитектурный каркас. Этап 0 принят пользователем; этапы 2–8 не выполнялись.

## Что изменено

- Сохранён React/Vite frontend. TypeScript 6 выбран для совместимости с линтером и анализатором; strict-настройки сохранены, Domain дополнительно проверяется без DOM/Node.js ambient-типов.
- Созданы слои Presentation, Application, Domain и Infrastructure. Единственная точка создания адаптеров — `app/create-services.ts`.
- Выделены интерфейсы AIProvider и StorageRepository, сценарии Settings и CheckConnection. SettingsPage получает прикладные действия через props и не вызывает хранилище или API напрямую.
- Reader, Vocabulary, Grammar, History и Settings имеют каталоги с описанием ответственности. Учебные функции и модели, IndexedDB и будущие промпты не реализованы.
- Добавлены ESLint 10, React Hooks rules, Prettier, EditorConfig и dependency-cruiser. Проверяются направления импортов, отсутствие циклов, включая type-only, запрет прямых SDK/browser IO в UI/Domain/Application.
- GitHub Actions дополнен lint, format check и architecture check перед тестами, build и публикацией.
- Добавлены unit-тесты Settings/Repository и проверки архитектурных нарушений; сохранены проверки этапа 0.
- Обновлены README, AGENTS и приёмка этапа 0; архитектура описана в `docs/architecture.md`.

## Данные и ограничения

Имена localStorage `vibe.openai-api-key` и `vibe.openai-model` сохранены. Формат данных и алгоритм тестового запроса не изменены; миграции не требуются. Текущий StorageRepository описывает только используемые настройки. Контракты учебных репозиториев и полная модель данных будут добавляться в этапе 2.

Новые функции в пользовательском UI не добавлены. Архитектурные проверки обнаруживают статические импорты и обычные обращения к browser IO; review остаётся необходимым для динамических обходов. Проверки UI используют mock API, действующий ключ в сборке и тестах не используется.
