# Этап 0 — отчёт

Дата: 2026-10-12. Объём: только техническая реализуемость. Этапы 1–8 не выполнялись.

## Реализовано

- Минимальное React + TypeScript strict приложение, Vite production build с базой `/vibe/`.
- Экран ввода, сохранения, замены и удаления API key; модель конфигурируется. localStorage используется только для ключа и модели, IndexedDB не добавлена.
- Явный тестовый запрос через прикладной сценарий и отдельный адаптер `fetch` к Responses API. Нет backend, SDK, фоновых запросов или автоматических retries.
- Индикатор загрузки, блокировка повторов, отмена и таймаут 20 секунд. Понятные ошибки ключа, разрешений, лимита, модели, сети/CORS, неполного/некорректного ответа.
- Отдельный английский промпт проверки подключения, версия 1. Учебные промпты и функции не добавлены.
- GitHub Actions: установка по lockfile → типы → unit-тесты → production build → браузерные mock-проверки → Pages artifact и deployment.
- README, AGENTS и этот отчёт. Исходные требования и план не изменены.

## Выполненные проверки

| Проверка | Результат |
| --- | --- |
| `npm run typecheck` | Успешно, TypeScript strict |
| `npm test` | 18/18, mock transport/provider, без действующего ключа |
| `npm run build` | Успешно; JS около 227 kB / 71.5 kB gzip, CSS около 1.27 kB |
| `npm run test:browser` | 6 групп проверок прошли на production preview в Chromium с мобильным viewport 390×844 |
| Перезагрузка и локальные настройки | Ключ/модель восстановлены, удалённый ключ не восстанавливается; автоматических запросов нет |
| Mock AI и ошибки | Успех, loading, исключение повторов, HTTP 401 без утечки текста ошибки, сеть, успешная повторная попытка |
| Unit-ошибки и контроль запросов | 400/401/403/404/429/500, валидация ответа, отмена, таймаут, дубликаты и redaction |
| Production base URL | Все пути assets начинаются с `/vibe/assets/`; загрузка и обновление проверены в браузере |
| Паттерны секретов | В 15 файлах исходников, тестов, зависимостей и dist OpenAI key не обнаружен; действующий ключ не использовался |
| Реальный CORS preflight | HTTP 200 для origin `https://serssp.github.io`; разрешены POST, `authorization,content-type`; allow-origin `*` |
| `npm run check:cors` | Реальный Chromium со страницы GitHub Pages прочитал HTTP 401 на POST с заведомо неверным тестовым ключом; API не подменялся |

Браузерные проверки исправили проблему контекста нативного `fetch`: адаптер использует привязку к globalThis. Финальные mock-проверки успешно прошли после исправления.

Наличие [browser-side режима SDK](https://developers.openai.com/api/reference/typescript) исследовано. Для минимального запроса выбран стандартный `fetch`; версия API и форма ответа соответствуют Responses API. Реальные CORS-проверки выше подтверждают доступность HTTP-ошибки для текущего origin, но не ответ модели с действующим ключом.

## Критерии приёмки

| Критерий плана | Статус |
| --- | --- |
| GitHub Pages открывается на Android Chrome | Не проверено: нет доступа к реальному телефону |
| Приложение загружается после обновления | Подтверждено в локальном production Chromium; опубликованная версия ещё не проверена |
| OpenAI отвечает на тестовый запрос | Не подтверждено с действующим ключом; CORS и реальный отказ 401 проверены |
| Неверный ключ показывает понятную ошибку | Подтверждено mock UI; реальный HTTP 401 прочитан отдельной браузерной CORS-проверкой |
| Ключ отсутствует в Git/build artifacts | Скан исходников и dist пройден, реальный ключ не использовался |
| CI собирает и публикует | Workflow подготовлен; запуск новой версии ещё не выполнен |

## Оставшаяся проверка

Публикацию и результаты нового CI нужно подтвердить отдельно. На Android Chrome открыть https://serssp.github.io/vibe/, обновить страницу, ввести действующий ключ непосредственно в приложение и выполнить тест. Затем проверить неверный ключ, отключение сети, замену и удаление ключа. Не отправлять ключ в чат или отчёт.

Этап 0 пока не принят: остаются реальный ответ модели и Android Chrome. При блокировке прямого API сообщить причину и варианты, не добавляя backend. Следующий этап не начинать.
